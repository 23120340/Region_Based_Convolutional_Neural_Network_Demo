# Tài liệu dự án Earbud Assembly

Đọc theo thứ tự sau:

1. [VIEC_BAN_CAN_LAM.md](VIEC_BAN_CAN_LAM.md) — checklist chính xác phần bạn phải thu thập, gán nhãn và train.
2. [KAGGLE_TRAIN_EARBUD_COCO.md](KAGGLE_TRAIN_EARBUD_COCO.md) — chuyển COCO sang YOLO, train và tải checkpoint từ Kaggle.
3. [LSTM_Training_Guide.md](LSTM_Training_Guide.md) — năm bước Annotation → Split → DINOv2 → BiLSTM → Evaluation.
4. [CAMERA_REALTIME.md](CAMERA_REALTIME.md) — chọn camera, chụp ảnh detection và chạy realtime.
5. [VIEC_BAN_CAN_LAM_GEOMETRY.md](VIEC_BAN_CAN_LAM_GEOMETRY.md) — quy tắc bounding box sáu lớp geometry trái/phải.
6. [HYBRID_VIT_LSTM_ASSEMBLY_PLAN.md](HYBRID_VIT_LSTM_ASSEMBLY_PLAN.md) — kiến trúc và cách mở rộng.
7. [ACTION_PIPELINE_V2.md](ACTION_PIPELINE_V2.md) — lệnh tóm tắt cho action v2.
8. [TOM_TAT_HOP_NHAT_REPO_20260922.md](TOM_TAT_HOP_NHAT_REPO_20260922.md) — các thư mục đã so sánh, phần đã giữ và phần đã loại.
